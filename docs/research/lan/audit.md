## Already works across hosts unchanged

- Snapshot file format (schema 3 key=value text, writer `host/pid/start` triple, `cityLoadedAt`) is plain text, endian- and path-independent (src/NeighborSnapshot.cpp:160-300). `writerHost` is already in the file and `IsValidWriterHost` bounds it.
- Atomic write (tmp then rename) is valid on SMB for the normal case (NeighborSnapshot.cpp:122-155); the `.snapshot` filter ignores `.tmp`.
- Instance status file format (src/InstanceStatus.cpp:648-704) already carries host/pid/start and is host-aware: `IsReapable` refuses to delete foreign files, `IsAlive` returns Unknown (not Dead) for foreign hosts, so a live remote writer is never wrongly deleted. Fail-safe direction.
- `PeerSnapshotChanged`/`storeSeen` compares mtime equality, not absolute times, so it tolerates host clock differences.
- Publisher-session tracking in NeighborMirror (CheckPublisherSession, NeighborMirror.cpp:297-310) already includes `host` in the session key.
- `writtenUnixTime` is never compared (informational).
- GetTickCount64 timers are intra-process only.
- The game's "SimCity 4 Mutex" release is per host and unneeded on the second PC; Unlock logging a 0 close is harmless.
- Per-host logs and `-UserDir` private data (Albums, cfg) are local by design; process-start `FILETIME` identity is only compared on the same host.
- Per-process state (SaveHook641 install, region watch handles) is local by nature.

## Suggested minimum set for a first LAN trial

1. #7 (UNC `StoreDirectory` in both inis) and #10 (symlink to the shared Regions).
2. #1 and #2 (file locks replacing both named mutexes).
3. #4/#5 (heartbeat liveness) and #6 (triple identity compare) so crashes do not leave ghosts.
4. #12 poll fallback; #17 only if the PCs are not time-synced.
